# Projeto Login

Tela de login responsiva desenvolvida com HTML, CSS e Media Queries, com foco em mobile first e interfaces modernas.

🔗 [Ver deploy](https://tiagogdl.github.io/projeto-login/)

---

## 📋 Sobre

Projeto desenvolvido para praticar responsividade e construção de interfaces com HTML e CSS puro. A tela de login se adapta a diferentes tamanhos de tela com design limpo e moderno.

## ✨ Funcionalidades

- Layout responsivo com Media Queries
- Abordagem mobile first
- Design moderno com inputs e botões estilizados
- Adaptação dinâmica para desktop e mobile

## 🚀 Tecnologias

- HTML5
- CSS3
- Media Queries
